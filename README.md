# UTS_RAFKYMAULANA

Tugas Ujian Tengah Semester (UTS) Pemrograman Aplikasi Bergerak (Android) oleh **Rafky Maulana** (`rafkymaulana411-star`).

## Deskripsi Aplikasi
Aplikasi Android berbasis Java untuk perhitungan gaji dan navigasi activity:
- **MainActivityRafky**: Halaman menu utama aplikasi.
- **GajiActivityRafky**: Form input data pegawai, golongan, dan tunjangan untuk menghitung rincian gaji.
- **HasilGajiActivityRafky**: Menampilkan ringkasan total dan rincian gaji pegawai yang telah dihitung.
- **PetunjukActivityRafky**: Petunjuk penggunaan aplikasi.
- **TentangActivityRafky**: Informasi pengembang / tentang aplikasi.

---
*Dibuat menggunakan Android Studio.*
